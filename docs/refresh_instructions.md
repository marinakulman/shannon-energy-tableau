# Обновление данных

1. Положить новые исходные CSV в корень папки проекта. **Исходники не редактировать.**
2. Обновить дату среза в `scripts/prepare_data.py`:
   ```python
   DATA_AS_OF = pd.Timestamp('YYYY-MM-DD')
   ```
   Менять дату среза только вместе с подготовкой набора, а не переключением в интерфейсе.
3. Выполнить:
   ```bash
   cd ShannonEnergy/scripts && python3 prepare_data.py
   ```
4. Проверить таблицу контроля в конце вывода — должно быть **OK по всем строкам**.
   При расхождении формулы под ответ **не подгонять**. Искать причину:
   пробелы в ключах, дубли, формат дат, детализация соединений, LEG,
   наблюдаемость или область фильтра.
5. Проверить `docs/` на появление `unmapped_channels.csv` или
   `conflicts_duplicate_customerid.csv` — они создаются только при проблемах.
6. В Tableau обновить экстракты и обновить константу `DataAsOf`.

Требования: Python 3 с `pandas` и `numpy`. Скрипт ничего не отправляет во внешние сервисы.
